ADOC — Write-Stall Mitigation for RocksDB

Problem: RocksDB stalls writes under heavy load when its LSM-tree components overflow.

Built: reproduced the ADOC algorithm (USENIX FAST '23) in C++17; polls the engine every second, classifies the overflow and auto-tunes threads + batch size with an AIMD policy via a custom EventListener.

Result: write-stall time from 15.63 s to 0 s at 138 kOps/s (60 s, 4-writer benchmark); 23-case suite passing.
